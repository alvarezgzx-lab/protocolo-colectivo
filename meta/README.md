# Meta / Modo de Trabajo

Skills que no producen contenido de un dominio específico, sino que definen **cómo Claude debe trabajar** — capas de proceso que se aplican antes o alrededor de las demás skills de este repositorio, sin importar el dominio.

## Skills en esta categoría

| Skill | Qué hace |
|---|---|
| [`reflexion-estructurada/`](./reflexion-estructurada/) | Modo de trabajo reflexivo para tareas sustantivas: detecta si una tarea amerita pausar a alinear expectativas antes de ejecutar, cruza la solicitud por 2-4 lentes expertas internas, expone huecos y supuestos, y confirma un esquema de fases antes de proceder. |
