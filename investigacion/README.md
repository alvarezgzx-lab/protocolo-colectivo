# Investigación

Skills que procesan y analizan material de origen (actividades de curso, lecturas, documentos) para producir salidas estructuradas y accionables — transcripción fiel, síntesis, y prompts o ideas derivadas del material.

## Skills en esta categoría

| Skill | Qué hace |
|---|---|
| [`analista-actividades-curso/`](./analista-actividades-curso/) | Procesa una actividad práctica de un curso o bootcamp y entrega transcripción literal, resumen ejecutivo, prompts avanzados de IA, ideas de skills, y recursos descargables. |
